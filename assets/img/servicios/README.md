Agrega aquí las fotos de las tarjetas de servicios. También puedes dejarlas directamente en `assets/img/`. La portada detecta las extensiones `.jpg`, `.jpeg`, `.png` o `.webp` con estos nombres base:

- `medicina-general`
- `cirugia-especializada`
- `medicina-complementaria`
- `diagnostico-imagenes`
- `laboratorio`
- `otros-servicios`

Ejemplo: `medicina-general.jpg`. Mientras falta una imagen, la tarjeta muestra un icono.
