# Veterinaria Ralah Pets

Sistema web para la gestión integral de citas, mascotas, clientes y atención veterinaria.

## Requisitos
* PHP >= 8.2
* MySQL / MariaDB >= 10.4
* Composer 2.x
* Apache con soporte mod_rewrite
